# 노래 맞추기 일꾼

가사 줄이 노래의 몇 초에 불리는지를 더 정확히 재기 위한 작은 서버다.

## 하는 일과 안 하는 일

```
노래 파일 → [반주 분리] → [단어 단위 인식] → 낱말과 시각
                                                  ↓
                              앱이 아는 가사에 겹친다 (frontend/lib/align.ts)
```

겹치는 계산은 **앱에 그대로 둔다.** 테스트로 묶여 있고, 순서를 지키는
전역 정렬이라 받아쓴 글자가 틀려도 견딘다. 이 서버는 "무엇을 들었나"만
바꾼다 — 정렬 규칙이 두 곳에 있으면 언젠가 어긋난다.

## 왜 이게 더 정확한가

| | 지금 (구글 STT) | 이 일꾼 |
|---|---|---|
| 반주 | 섞인 채로 인식 | Demucs 로 목소리만 떼어 냄 |
| 시각 | 문장을 받아쓰고 낱말 시각을 어림 | wav2vec2 로 소리와 글자를 직접 맞춤 |

## 띄우기

```bash
docker build -t toktok-align .
docker run -d --restart=always -p 8080:8080 \
  -e ALIGN_WORKER_TOKEN='앱과 나눠 가질 긴 문자열' \
  toktok-align
```

첫 요청에 모델을 내려받느라 몇 분이 걸린다. `GET /health` 로 살아 있는지
확인한다.

## 앱에 연결

Vercel 환경변수 두 개를 넣고 재배포한다.

```
ALIGN_WORKER_URL=https://<서버주소>/align
ALIGN_WORKER_TOKEN=<위와 같은 문자열>
```

넣지 않으면 앱은 지금까지 쓰던 구글 STT 로 맞춘다. 일꾼이 죽어 있어도
마찬가지다 — 맞추기 하나 때문에 회기가 멈추지는 않는다.

## 어르신 음성은 오지 않는다

여기로 오는 것은 **만들어진 노래**뿐이다. 인터뷰 녹음은 이 서버를 거치지
않는다. 받은 파일은 답을 보내고 나면 지운다.
